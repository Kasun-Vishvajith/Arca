## What is Arca?

Arca is a macOS-inspired desktop workspace that runs entirely in the browser —
no installation, no backend, no cloud account required. It is built as a
personal productivity shell: a private, fast, and elegant environment you can
use and extend as your own.

> ⚠️ **This project is actively in development.** Features marked *coming soon*
> are on the roadmap and will land in upcoming releases.

## Getting Started

**Requirements:** Node.js 18+

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev


## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Build for Production

```bash
npm run build
npm run serve
```
